# Divyesh Gaygol Portfolio

My personal portfolio website built with Vue and Vite.

## About

This portfolio showcases my projects, technical skills, experience, and contact information. It serves as a central place to explore my work in backend development, distributed systems, Android development, and developer tooling.

## Features

* Responsive design
* Dark/Light mode support
* Project showcase
* Skills and experience section
* Contact form powered by EmailJS
* Smooth animations with AOS

## Tech Stack

* Vue 3
* Vite
* JavaScript
* EmailJS


## Run Locally

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```
